# Several screens (test feature)

More than one screen on one kitchen. A test feature, not part of the normal install. Nothing has been tried on real tablets.

## What you need

A main computer (the hub): a small program on one computer that keeps the shared kitchen and sends it to every screen. Someone runs it by hand. Smokebox never starts one. You need its address, and its access code if it has one. Then tap **Settings**, then **Use one kitchen on several tablets**.

## Show only

For a TV or phone. Tap **Show only**, type the **Address of the kitchen** and the code, and tap **Connect**. The screen says "Connected" and "This screen only shows the kitchen." It cannot take or change orders. To leave, tap the menu button at the top right, then **Back to my own kitchen**.

## Use the main computer for orders

For a tablet that takes orders too. Tap **Use the main computer for orders on this tablet**. Type the **Address of the main computer** and a name, like Pass. Tap **Check the main computer**, then choose one:

- Show the shared kitchen on this tablet. Your own saved kitchen stays untouched.
- Send this tablet's kitchen to the main computer. This works only if it has no kitchen yet. It never mixes two kitchens.

Then tap **Join this kitchen**. Tap **Leave the shared kitchen** to go back.

If the main computer asks for a **Pairing code**, ask the person who runs it. Type it and tap **Pair this tablet**. The code works once and lasts 10 minutes. If it says "This tablet has been removed from the kitchen", tap **Leave and pair again** and ask for a new code.

## What the board tells you

- "Connected": your taps are reaching the main computer.
- "Offline: your taps are saved and will be sent": taps wait on this tablet.
- "Last known, from" a time: the page reloaded while the main computer was down, so it shows the last kitchen it had.
- "Not confirmed yet" on a ticket: no answer to that change yet.
- "Not done:" and a reason: the main computer refused a tap, for example because another tablet was first.

## Undo

**Undo** works only on your own last action, while nobody else has acted since. Otherwise it says "Someone else changed the kitchen since" and you fix it by hand.
