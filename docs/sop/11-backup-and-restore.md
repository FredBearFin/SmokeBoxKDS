# Backup and restore

Everything Smokebox knows is saved in this browser on this device. A backup is a file you keep somewhere else.

## Make a backup

1. Tap **Back office**, then **Menu and settings**.
2. Find Data, backup and reset. In the first card, **Back up now**, tap **Download backup (JSON)**. Or tap **Copy backup** and paste the text into an email to yourself.
3. Keep a copy off this device.

Back up every day at close. If the browser data is cleared or the device is replaced, a copy on the same device goes with it.

## Restore from a backup

1. In the second card, **Restore from a backup**, tap **Choose a backup file**. Pick the newest one, named smokebox-backup-(date).json. Or paste the text and tap **Check pasted backup**.
2. Read the summary: the saved date, the tickets and the batches should match what you expect. Nothing has changed yet.
3. If it is right, tap **Replace everything with this backup**. This replaces all data on this device, including the PIN. There is no undo, so back up what is here first if you might want it.
4. Open the board and check your menu and your food. Sound and loudness are set per device, so test them again.

A file that is not a valid backup is refused, and nothing is changed. A backup from the demo is refused too.

Spreadsheet files, like the sales file, cannot be restored.

## Start over with an empty menu
1. Tap **Settings**. At the bottom, tap **Start over with an empty menu**.
2. Read what goes and what stays. Clear **Keep my tax, hours, PIN and station names** to reset those too. Tap **Next: about your backup**.
3. This step only explains: the backup is saved at the moment of erasing, and if it fails, nothing is erased. Tap **Next: confirm**.
4. Type ERASE, then tap **Erase everything and start over**.
5. At "Done. Your kitchen is empty." tap **Save the backup again** or **Go to the first screen**.

There is no undo. To go back, restore the backup file. Left-over old demo tickets get **Clear them** or **Keep them**.

## Erasing

The Danger zone has **Erase live data** and **Erase everything**. Each one asks you to type a word first, so it cannot happen by accident. Back up before you use either.
