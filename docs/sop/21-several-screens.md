# Several screens (test feature)

More than one screen on one kitchen. This is a test feature, not part of the normal install, and nothing has been tried on real tablets.

## What you need

The main computer (also called the hub) is a small program that keeps the kitchen in one place. Someone runs it by hand. Smokebox never starts one. You need its address and, if it needs one, a pairing code or an access code. Then tap **Settings**, then **Use one kitchen on several tablets**.

## Show only

For a TV or a phone. Tap **Show only**, type the **Address of the kitchen** and the code, and tap **Connect**. The screen says "Connected" and "This screen only shows the kitchen." It cannot take or change orders. To leave, tap the menu button at the top right, then **Back to my own kitchen**.

## Use the main computer for orders

For a tablet that takes orders too. Tap **Use the main computer for orders on this tablet**. Type the address and a name for this screen, like Pass. Tap **Check the main computer**. If it asks for a pairing code (one use, 10 minutes), type it in **Pairing code** and tap **Pair this tablet**. Then choose one:

- Show the shared kitchen on this tablet. Your own saved kitchen stays untouched.
- Send this tablet's kitchen to the main computer. This works only if the main computer is empty. Smokebox never mixes two kitchens.

Then tap **Join this kitchen**. Tap **Leave the shared kitchen** to go back. If removed, tap **Leave and pair again**.

## What the board tells you

- "Connected": your taps are reaching the hub.
- "Offline: your taps are saved and will be sent": the link is down. Taps wait on this tablet.
- "Last known, from" a time: the page reloaded while the hub was down, so it shows the last kitchen it had.
- "Not done:" and a reason: the hub refused a tap, for example because another tablet got there first.

## Undo

**Undo** works only on your own last action, and only while nobody else has acted since. Otherwise you see "Someone else changed the kitchen since, so this cannot be undone from here. Fix it by hand."
