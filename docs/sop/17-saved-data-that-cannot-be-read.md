# Saved data that cannot be read

What to do when Smokebox says some of its saved data could not be read.

## A message at the top

If a message says some saved records could not be read and were left out, the data as it was is kept. Do not clear the browser data. Ask whoever set up Smokebox. If a full-screen message says the saved data could not be read, tap **Download the old data** or **Show the data so I can copy it**. Only then can you continue.
