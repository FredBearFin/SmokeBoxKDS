# Hostile data on every screen: DOM injection audit

Branch `night/a1-fix2`. Checked by reading every use of the sinks below in `src/js/*.js` and by `test/hostile-data.e2e.mjs`, which fills the
kitchen with hostile text and opens every screen. Nothing here was tried on a real device.

## What the test does (`test/hostile-data.e2e.mjs`)

Fills a backup (imported through `importAll`), the owner station, category and channel names, ticket and order text, dish, ingredient and
batch names, modifiers, initials, thrown-out log notes, readings names and a second backup with hostile ids with 16 strings: markup with
`onerror`, a script tag, `javascript:`, a style break, template and CSS tricks, right-to-left override, zero-width and control characters,
emoji, spreadsheet formulas and two 50,000-character strings. Then it opens the board (every station tab, the Cabinet tab, far display,
wall mode at 1920), 20 sheets (order, Orders, Recall, Hold, 86 board, Demo, Help, Specs, Settings, thrown-out log, Readings, setup, dishes,
tax and PIN, tablet checks, pilot, how you serve, menu import, cooked-ahead, wizard), the payment box, the menu import preview with a hostile
file, the Guide search with hostile queries, all seven office pages, the print buttons and the download buttons, and the CSV exports.
After each one it checks: `window.__pwn` never set, no element made from the text (no `img[src=x]`, no `onerror`, no new script), no
horizontal page scroll at 1024 px, no uncaught error and no dialog.

Result on this branch: all checks pass (the thrown-out log CSV failed before the fix).

## Fields with no length cap at the import door (for A5)

A backup (`importAll`) keeps a 50,000-character string in each of these; the screens survive it (the test shows no layout explosion and no
horizontal scroll), but a cap would protect storage, the one-second tick and the print and CSV sizes:
`menu[].name`, `menu[].short`, `ingredients[].name`, `ingredients[].note`, `tickets[].customer`, `tickets[].note`, `tickets[].items[].name`,
`tickets[].items[].short`, `batches[].label`. The station, category and channel names are capped (a long one is refused), and order and event
text fields were repaired or dropped by the import in this run.
